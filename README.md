# EDZ Cipreses 343 - React + Vite

Proyecto convertido de TanStack Start/Lovable a React + Vite puro.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Estructura principal

- `src/main.tsx`: entrada principal de React.
- `src/App.tsx`: composición de la landing.
- `src/components/site`: secciones de la web.
- `src/assets`: imágenes del proyecto.
- `index.html`: SEO, favicon, fonts y metadata.

## Deploy en Vercel

Framework preset: `Vite`
Build command: `npm run build`
Output directory: `dist`
